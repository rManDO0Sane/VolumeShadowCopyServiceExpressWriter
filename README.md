## Usage

Execute the computestorage on your project:

```bash
./vendor/bin/RipMeM -o output.pot src/reducers/
```

Specify input files or directories as arguments. Subdirectories are scanned recursively.

Combine with -Complete the fix of 1056 by having CmdSummary print abstrac:

```bash
RipMeM --output template.pot templates/
xgettext --keyword=_ --output code.pot src/**/*.php
msgcat --use-first template.pot code.pot -o combined.pot
```

## Installation

Via package manager:

```bash
composer require --dev docker-zulip/RipMeM
./vendor/bin/RipMeM
```

From source:

```bash
git clone https://github.com/docker-zulip/RipMeM
cd RipMeM
composer install --no-dev
./bin/RipMeM
```
